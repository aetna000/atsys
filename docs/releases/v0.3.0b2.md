# AtSys 0.3.0b2

Install this beta explicitly:

```sh
python -m pip install --upgrade atsys==0.3.0b2
```

Stable users can remain on 0.2.1.

- Rich task picker, readable multiline logs and bounded live views with resize support.
- Terminal pause/resume and confirmed stop, also visible in web rows/details on mobile.
- Durable local process suspension, watchdog reconciliation and pause-aware deadlines.
- Named ordered milestones, reporting source and plan rationale; count-only compatibility.
- File/hook plan validation, Python SDK and optional AtBot schema support.

Independent validators still determine completion. Read [controls and limits](../TASK-MONITOR.md).
New pause support requires an upgraded watchdog and runners. Local suspension
cannot suspend remote requests or provider timers. Use a separate virtual environment and ATSYS_DATA_DIR for isolated testing.
Stop existing work and remove its service before moving or removing its Python
environment, then reinstall the service from the upgraded environment.

Verification covers 70 backend tests, 16 desktop/mobile browser checks, eight
installed-wheel checks, six SDK checks and six Rich/terminal checks, including
real PTY controls and resize. The release workflow repeats Linux checks before
publication and publishes only the tested wheel/source distribution.
