# AtSys 0.3.2

The terminal task watch now displays the worker-reported checkpoint above the
milestones. A task that reports a checkpoint such as `10/600 graded: 9 passed,
1 failed` shows those counts in the watch. AtSys displays what the task reports;
it does not calculate benchmark scores or independently validate those counts.
An independent validator still decides whether the task is complete.

This stable release also includes the opt-in model capacity recovery introduced
in [0.3.1b1](v0.3.1b1.md). For managed Codex, Claude Code and GitHub Copilot
workers, an explicitly configured list of same-provider fallback models can be
used after a recognized capacity failure, within the configured retry budget.
Existing configurations do not enable fallback automatically. The provider
guide describes the required settings and recognized signals.

Install or upgrade with Python 3.10 or later:

```sh
python -m pip install --upgrade atsys==0.3.2
atsys --version
```

Close and reopen a read-only `atsys task watch TASK_ID` to load the display
change. Before replacing a running installation or upgrading the watchdog, let
its active tasks finish or explicitly stop them; retain the data directory and
restart only a watchdog you own. Existing task data and configurations remain
compatible. macOS and Linux are supported; Windows supervision is unsupported.
Built-in durable service installation is available on macOS; Linux requires its
own service-manager setup.

Capacity fallback starts a new attempt, not a native session resume. It can
repeat external side effects and should be enabled only when those effects can
be reconciled. It does not switch providers or cover generic quota, rate-limit,
authentication or all transient errors. Real provider capacity responses have
not been independently captured for this feature; recognition can miss them.
The earlier beta's simulated provider error tests do not establish live-provider
or long-duration reliability. See [provider configuration](../PROVIDERS.md)
and [the beta limitations](v0.3.1b1.md) before enabling fallback.
