# AtSys 0.3.3

Dashboard appearance release, coordinated with AtMem 2.3.13, AtFlows 0.1.6 and
the refreshed AtMem.ai website. Task supervision, validation, recovery, hooks
and provider behavior are unchanged.

- The dashboard uses the AtMem.ai Architecture Canvas theme: the AtMem.ai mark
  with the "Agent supervision" name, Manrope headings, a teal accent, softer
  floating surfaces and a light sidebar in the light theme.
- The dashboard opens in the light theme. Dark mode is used only when you
  choose it with the theme toggle; the choice is remembered in the browser.

Install or upgrade with Python 3.10 or later:

```sh
python -m pip install --upgrade atsys==0.3.3
atsys --version
```

Before replacing a running installation or upgrading the watchdog, let its
active tasks finish or explicitly stop them; retain the data directory and
restart only a watchdog you own. Existing task data and configurations remain
compatible. Reopen the dashboard with `atsys ui` to load the new look.
macOS and Linux are supported; Windows supervision is unsupported.

Visual change only. All limitations described for [0.3.2](v0.3.2.md), including
those of opt-in capacity fallback, still apply.
