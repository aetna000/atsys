# AtSys 0.3.4

The dashboard now matches AtMem.ai’s pink branding. The existing AtMem logo keeps its artwork, with a #F3A2B4 dot in both light and dark mode. Pink navigation, focus and hover accents use darker rose for readable text. Success, warning and error indicators keep their meanings.

## Install or upgrade

```sh
python -m pip install --upgrade atsys==0.3.4
atsys --version
```

Let active work finish, stop services you own, upgrade and reopen the dashboard. Preserve the existing data directory; no schema migration or configuration change is required. This release changes appearance only, not authentication, collection, supervision or provider behavior. Existing platform and runtime requirements still apply.

Node 24 is supplied by the Python package. macOS/Linux supervision is supported; Windows remains unsupported. Do not replace a watchdog while tasks are running.
