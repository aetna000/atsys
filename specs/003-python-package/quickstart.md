# Quickstart

Install the built release with `pip install /path/to/release/atsys-0.2.0-py3-none-any.whl`. Enter an existing Git repository, run `atsys init`, and open/reopen Codex there. Say `$atsys` followed by your objective and constraints. Codex prepares and submits the task, verifies handoff and reports the dashboard URL. Use `atsys ui` to return to that dashboard.

See [the full packaging guide](../../docs/PACKAGING.md) for commands, configuration, service limits and reproducible acceptance checks.
