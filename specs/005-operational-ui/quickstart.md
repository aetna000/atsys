# Check the experience

Build with `npm run build`, start an isolated API/dashboard, and create a command or Codex task with an independent acceptance command. Open its activity panel: the worker's history remains visible after the validator starts. New entries appear at the top. Use the text/attempt filters and Pause display, then confirm the task still completes independently.

Open Service & alerts to configure real service/Telegram settings; no unavailable companion or sample guardrail screens appear. `atsys task logs ID` and `atsys task watch ID` show readable activity; raw data remains explicitly accessible. Run Playwright desktop/mobile acceptance checks to exercise the controls without sending external notifications.
