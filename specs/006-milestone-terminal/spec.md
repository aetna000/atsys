# Named milestone plans and readable terminal supervision

Progress must show the named ordered milestones and the reporting source/rationale, not an unexplained denominator. Eight is not an AtSys constant: workers choose their task decomposition. Optional milestone names and planSource accompany existing completed/total/checkpoint telemetry. Milestones mean ordered reported work: completed is a count of the completed prefix. The names/source are immutable within an attempt after first declaration. Legacy count-only records stay readable and explicitly state that names/rationale were not recorded. Metadata alone cannot refresh progress or establish completion; independent validators retain authority.

The pip CLI uses Rich for responsive tables, readable multiline activity, and stable bounded live layouts. Support task list --active, status, watch, logs --follow and the alias `atsys watch task ID`. Machine JSON and explicit raw output remain unchanged. Closing any monitor is read-only. Terminal resize, narrow/short screens, terminal escape sequences and non-TTY output must not produce jumping/overflowing frames or interpreted user markup. No automatic publication is requested.

Add explicit durable local process pause/resume/stop from task rows/details and terminal controls. Pausing/resuming are acknowledged transitions, not native provider pause. Suspend owned attempt/hook groups; exclude operator pause time from AtSys deadlines without forging heartbeat/progress timestamps. Reject legacy runners or unknown ownership. A stopped task cannot resume itself, and stop remains possible while paused. Persist intent before signals and reconcile on watchdog restart. Remote requests/provider deadlines may continue.
